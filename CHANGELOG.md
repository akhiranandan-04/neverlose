# Changelog

All notable changes to this documentation hub are recorded here. The hub version
is independent of the Neverlose build version.

## 1.0.0 - 2026-10-23

### Added

- Installation and first-launch guide for the legacy CS:GO client.
- Configuration workflow covering backups, profiles, scripts, and portability.
- Symptom-based troubleshooting guide and issue-report checklist.
- FAQ, safety notes, account-risk disclosure, and repository policy.
- Original banner, logo, download button, menu concept, and visual concept.
- 1280x640 social preview image.
- Issue templates, pull request template, and contribution guide.
- Automated validation for relative links, SVG assets, PNG signature, forbidden
  binaries, and placeholder text.

### Notes

- This repository is documentation-only and hosts no executables or archives.
- The download folder is external and controlled outside GitHub.
- Account safety, detection status, and vendor availability are not guaranteed.
