# Roadmap

The roadmap covers this documentation hub, not the Neverlose product. Vendor
features, build availability, and account support are outside this project's
control.

## 1.0.0 - baseline

- [x] Installation and first-launch guide
- [x] Configuration backup and script hygiene guide
- [x] Symptom-based troubleshooting guide
- [x] FAQ, safety notes, and scope statement
- [x] Original banner, download button, and interface concepts
- [x] Social preview image for the repository
- [x] Issue templates and pull request checklist
- [x] Automated link, asset, and repository-policy validation

## Next

- [ ] Add a legacy CS:GO compatibility checklist
- [ ] Add a config backup example with a dated folder layout
- [ ] Add a troubleshooting decision tree for menu and overlay failures
- [ ] Add more original interface concepts for the documentation pages
- [ ] Improve issue triage labels and maintainer notes
- [ ] Add a translation structure if enough reviewers volunteer

## Not planned

- Hosting loaders, DLLs, executables, archives, or license keys.
- Selling access, accounts, configs, or "unban" services.
- Mirroring vendor files or bypassing platform moderation.
- Instructions for evading anti-cheat or detection.
- Fake stars, purchased engagement, or artificial activity.

## How items are chosen

Work is prioritised by how many support questions it prevents, not by how
impressive it looks. A short, accurate page that stops a repeated mistake is more
valuable than a large page nobody can verify.

Suggest a roadmap item through the guide request issue template. Include the
problem it solves and the source of the information you want documented.
