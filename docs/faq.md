# FAQ

## Is this the official Neverlose repository?

No. This is an independent community documentation hub. It is not affiliated
with Neverlose, Valve, or Steam. The vendor controls the product, its pricing,
its availability, and its support channels.

## Does this repository contain the cheat or its source code?

No. It contains documentation, original diagrams, interface concepts, and a link
to an external download folder. There are no loaders, DLLs, executables, archives,
license keys, or source dumps in this repository.

## Does it work with CS2?

This hub targets the legacy CS:GO client. CS2 is a different game with different
binaries and is not covered by these instructions. If your Steam library only
offers CS2, this guide cannot restore the legacy client.

## Is Neverlose free?

This repository does not sell, license, or activate Neverlose. Access terms are
set by the vendor. Do not send payment to anyone who claims to be an official
reseller based on this repository; this hub has no reseller program.

## Is it undetected?

No one can guarantee that. Third-party software can be detected at any time, and
using it can lead to a VAC or game ban. This repository makes no claim of
undetectability and cannot verify claims made elsewhere.

## Why are the preview images illustrations?

The images are original interface concepts made for this hub. Using original
artwork avoids copyrighted game captures and avoids presenting a mock-up as
proof of current in-game behavior. They are labelled as concepts in the README.

## Where should I download it?

Use the [download folder linked in the README](https://www.mediafire.com/folder/xpuwhpaw2jpbi/neverlose).
Do not use reuploads, short links, or files from direct messages. If the folder
is unavailable, open an issue; do not trust a random mirror.

## Why does the repository not host the archive?

Keeping the repository documentation-only makes every change reviewable and
avoids turning GitHub into a mirror for executable files. It also reduces the
chance of a modified archive being mistaken for a trusted copy.

## Can I contribute a configuration?

Generic, original guidance about configuration hygiene is welcome. Private
profiles, account-specific files, and archives are not accepted. Read
[CONTRIBUTING](../CONTRIBUTING.md) before opening a pull request.

## Why is the repository named Neverlose if it is unofficial?

The name identifies the product the documentation is about. The first screen of
the README and the license section both state that this is an independent
project. Nothing here should be read as vendor endorsement.

## Can I get help with a ban or a broken account?

No. This hub cannot investigate bans, recover accounts, or negotiate with the
vendor or Valve. If an account is important to you, do not load third-party
software into the game.

## How do I report a broken link or an outdated step?

Open a documentation issue using the repository template. Include the page,
what you expected, and what happened. Remove account names, tokens, and personal
data before posting screenshots or logs.

## Is the repository actively maintained?

It is maintained on a best-effort basis. The [roadmap](../ROADMAP.md) lists the
next documentation work, and the [changelog](../CHANGELOG.md) records completed
changes. There is no guaranteed response time and no vendor support commitment.
